# 工具调用轨迹时间线展示

## 需求背景

当前工具调用轨迹展开后仍以卡片形式展示，视觉重量偏高；收起态展示工具名称和数量，不符合“只告诉用户已处理多久”的期望。

## 目标

- 折叠态显示“处理中/已处理 + 总耗时 + 箭头”，弱化技术细节。
- 展开态改成类似参考图的轻量时间线/操作记录行。
- 展开态仍可滚动，避免撑满侧边栏。
- 单条记录仍可展开查看工具输入和输出详情。
- 工具耗时由前端记录开始和结束时间，不要求后端协议变更。

## 修改范围

- web/SmartWord.WebClient/src/stores/chat.js
- web/SmartWord.WebClient/src/components/ThoughtActionTrace.vue
- 前端构建产物
- docs/已实现的功能.md

## 不在范围

- 不修改后端 AgentEvent 协议。
- 不展示模型私有思维链。
- 不改变工具执行、确认、审计或持久化流程。

## 实现方案

1. 在工具调用开始时记录 startedAt，完成/拒绝/跳过时记录 endedAt。
2. 组件内每秒刷新当前时间，用于运行中耗时展示。
3. 折叠态只渲染汇总按钮，显示总耗时和展开箭头。
4. 展开态渲染所有工具调用为紧凑时间线行，设置最大高度与纵向滚动。
5. 行内展示动作图标、用户可理解动作摘要、技术工具名和单条耗时；详情区保留输入/输出。

## 测试计划

- 运行 npm run build。
- 运行 git diff --check。
- 使用本地 Vite 测试页在 320px 宽度下验证折叠态、展开态和滚动行为。
- 验证长轨迹不会横向溢出，运行中耗时会刷新。

## 风险与注意事项

- 新增时间戳只在当前前端运行态生效，历史持久化数据若无时间戳需使用兜底展示。
- Word 侧边栏宽度较窄，时间线文字必须截断，详情内容继续独立滚动。
