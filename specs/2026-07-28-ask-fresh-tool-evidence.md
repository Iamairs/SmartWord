# Ask / Plan 模式刷新文档证据

## 需求背景

Ask / Plan 模式允许模型按需调用只读工具。即使没有对话历史，模型也可能跳过工具直接输出文本；存在持久化历史时，还可能复用历史回答或历史工具结果。这两种情况都会导致本轮没有工具事件，前端也就没有可展示的工具轨迹。

## 目标

- Ask 模式回答依赖当前 Word 文档内容的问题时，本轮必须调用只读工具刷新证据。
- Plan 模式生成依赖当前文档事实的计划时，本轮必须调用只读工具确认文档状态。
- 历史回答和历史工具结果只能作为检索线索，不能替代本轮读取。
- 保持与当前问题无关的普通问答不强制调用工具。
- 继续复用现有工具事件和前端时间线，不修改事件协议。

## 修改范围

- `src/SmartWord.AddIn/Resources/Prompts/ASK.md`
- `src/SmartWord.AddIn/Resources/Prompts/PLAN.md`
- Prompt 契约测试
- `docs/已实现的功能.md`

## 不在范围

- 不强制所有 Ask 请求调用 `probe_document`。
- 不修改工具执行器、权限系统或前端事件协议。
- 不展示模型私有思维链。

## 实现方案

1. 在 Ask 和 Plan 提示词中增加文档事实的新鲜证据规则。
2. 要求使用与问题匹配的最窄只读工具，而不是固定调用宏观探针。
3. 增加 Prompt 契约测试，锁定“不得仅依赖历史、本轮至少读取一次”的规则。

## 测试计划

- 运行 `SmartWord.Application.Tests` 中的 Prompt 契约测试。
- 运行 `git diff --check`。

## 风险与注意事项

- 文档内容问答会比直接复用历史多一次只读调用，但可确保证据与当前文档一致，并向前端产生真实可展示的工具轨迹。
- 与文档无关的通用问题仍允许直接回答，前端不会伪造不存在的工具调用。
