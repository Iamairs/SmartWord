# 文档终检

## 工作流

1. 先读取文档结构，判断标题层级、章节顺序和交付状态。
2. 优先检查会阻塞交付的问题：`TODO`、`XXX`、`待补充`、空标题、断裂编号、明显占位符。
3. 再检查质量问题：重复空格、异常标点、空段落、术语不一致、过长段落。
4. 输出按严重程度分组的问题清单。
5. 只有低风险机械修复可以在用户授权后执行，例如删除重复空格、修正明显标点、统一明确指定的术语。
6. 每次写入后必须验证受影响段落。

## 输出要求

- 使用“问题类型、影响位置、严重程度、建议处理方式”组织结果。
- 对不确定问题只提出审阅建议，不直接改写正文含义。
- 需要批量修改时，先给出计划并等待权限确认。

## 安全边界

- 不执行 `scripts/` 下的脚本。
- 不直接访问文件系统或 Word COM。
- 不绕过 SmartWord 的写入确认、Undo 和任务历史审计。
