# 术语一致性检查

## 工作流

1. 先扫描标题、正文、表格和关键章节，提取疑似术语。
2. 识别同义但写法不同的表达，例如“客户/用户”“甲方/委托方”“Smart Word/SmartWord”。
3. 生成候选术语表，标出推荐标准写法和出现位置。
4. 批量替换前必须让用户确认标准写法。
5. 替换后回读验证，避免误改专有名词或引用内容。

## 输出要求

- 区分“确定不一致”和“疑似不一致”。
- 给出段落位置，方便用户跳转核对。
- 对缩写首次出现建议补充全称。

## 安全边界

- 不执行 Skill 脚本。
- 不在未确认标准术语前批量替换。
